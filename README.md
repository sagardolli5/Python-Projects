# 🐍 Python Projects
One project at a time, one skill at a time.
## 📁 Projects
| Project | Description |
|--------|-------------|

## 🛠️ How to Run Locally
1. Clone the repo:
   git clone https://github.com/sagardolli5/Python-Projects.git

2. Go to the project folder:
   cd Python-Projects/project-name

3. Run the code:
   python main.py
