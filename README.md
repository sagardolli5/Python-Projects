## 🛠️ How to Run Locally
1. Clone the repo:
```bash
   git clone https://github.com/sagardolli5/Python-Projects.git
```
2. Go to the project folder:
```bash
   cd Python-Projects/project-name
```
3. Run the code:
```bash
   python main.py
```
